# La Escuela del Sur · EN / ES

Bilingual web edition of **“La Escuela del Sur: una tradición vigente”** by Lic. María Eugenia Méndez, originally published in **La Revista** Nº 375 (Octubre 2026).

Live site: [escuela-del-sur-en-es.pages.dev](https://escuela-del-sur-en-es.pages.dev)  
Original flipbook: [La Revista Nº 375 on Heyzine](https://heyzine.com/flip-book/095c92866d.html)
